# Projetos e Estudos em Análise de Dados (Python & Pandas)

Bem-vindo(a) ao meu repositório de **Análise Exploratória de Dados (EDA)** e **Tratamento de Dados**. 

Este espaço é dedicado a reunir projetos práticos desenvolvidos em Python, focados no ciclo completo de análise: desde a ingestão automatizada de datasets até a engenharia de atributos, regras de negócio e geração de insights.


## Tecnologias e Ferramentas Utilizadas

- **Linguagem:** Python
- **Manipulação e Análise:** Pandas
- **Ingestão de Dados:** `kagglehub`
- **Ambiente de Desenvolvimento:** Google Colab
- **Controle de Versão:** Git & GitHub

## Principais Conceitos Práticos Aplicados

1. **Ingestão e Padronização:** Leitura de arquivos `.csv` e padronização de nomenclatura de colunas para PT-BR.
2. **Engenharia de Atributos:** Criação de colunas calculadas (taxas percentuais, conversões e engajamento).
3. **Regras de Negócio e Categorização:** Segmentação de dados em níveis/faixas de desempenho usando funções nativas, expressões `lambda` e `.apply()`.
4. **Filtragem e Agregação:** Consultas condicionais de alta performance com `.query()` e estatísticas agrupadas com `.groupby()` e `.value_counts()`.
